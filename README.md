# Enron-Fraud-SQL-Detection
Portfolio project using SQL, Python, &amp; PostgreSQL to analyze 500k+ emails from Enron Corp to flag anomalous communication.

## Where to find data
Please download the file "emails.csv" from Kaggle uploaded by user wcukierski and place the file in "data/". The filesize is 1.3GB and is too large to store inside of this repo.
